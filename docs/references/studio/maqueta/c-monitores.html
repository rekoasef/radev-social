Boceto C · Pared de cámaras. La sala de control mira el estudio por circuito cerrado: el monitor grande de programa siempre muestra tu escritorio y lo que te espera, y alrededor está una cámara por oficina. Las que graban (punto rojo) están trabajando; las apagadas, con ruido, están libres; la que tiene borde rojo tiene una falla. Es la más fiel al panel actual (los monitores de la portada) y la más fácil de leer de un vistazo, pero la menos "juego". Animación prevista: imagen de cámara con leve parpadeo, y los personajes se mueven dentro de cada cámara. Se toca una cámara para entrar a la oficina.
